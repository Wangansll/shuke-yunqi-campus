## 二、已核验属实的能力（代码 + 数据交叉核对）

1. 页面与分包：12 个主包页 + `pkgFood` 分包，`app.json` 注册齐全；五项自定义 tabBar。
2. 美食分包：150 家店、2072 道菜、60 条销量榜；磁盘定稿配图 107 张；菜品字段含店名/校区/分类/月售/图/招牌/描述/AI 标记。主包只放统计数字，明细在分包。
3. 办事指南：15 件事、7 个分类，出处/步骤/材料清单/去处字段零缺失；支持搜索、分类筛选、材料勾选留进度、收藏。
4. 小栖对话：本地 BM25 检索（bigram 切分、停用词、同义词扩展、领域路由、口语短语保底、标题加权、归一化阈值）命中才注入系统提示；云端大模型流式输出、上下文上限 12/16、AbortController 中断防御、回答可展开引用来源。
5. 数据链路：服务端 SQL 全部参数化；openid 只取云托管注入的 `X-WX-OPENID`，忽略前端传参；凭据环境变量优先；云端不可用落本机 storage 并标注"未同步"；快递 100 正式接口 MD5 签名 + 公开通道降级；汇率走公开 API，取不到不兜底假数据。
6. 诚实边界：报修、站内点餐因无真实下游主动下线，改为办事指南 / 跳美团；不代查成绩课表账单取件码；无数据源显式提示；自检把"自建云函数/库被平台禁用（code 10 / -501000）"写明原因，不假装全绿。
7. 隐私处理：名单/成绩/表格类不入库，条目不含学号手机号；个人数据引导本人登录对应平台查看。
8. 模拟器实测补强（automator 走查 data 快照）：首页/对话/我的三页 `modelReady=true`、`modelName=云端模型`，云端大模型链路在工具内连通；东盟页 `fxReady=true`、`fxTime=11-18 08:02`，100 CNY 兑 506.41 THB，实时汇率取到；我的页 `cloudLogin=true`、openid 脱敏 `oUncpx…BOwE`、身份已绑云端账号；美食分包 `total=2072 / voiceTotal=150 / board=60`，首页与图鉴计数一致；办事指南 `total=13 / catN=7`；百科 `gallery=4 / hot=10`。
