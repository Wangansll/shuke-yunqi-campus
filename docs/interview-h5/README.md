# 面试演练 H5（档位 2/3 外跳版）

独立静态页面，部署到已备案的 HTTPS 域名后，由小程序复制链接在浏览器打开。小程序内**不使用 web-view 内嵌**（个人主体不开放）。

## 三档对应

| 档位 | 形态 | 落点 |
|---|---|---|
| 1 文字对话 | 小程序原生页，打字作答 | `pages/interview/index` |
| 2 语音对话 | 小程序内录音转文字（回合制）；H5 `index.html` 为网页版 | 小程序面试页语音模式 / `index.html` |
| 3 实时视频对话 | 浏览器 H5，摄像头本地预览 + WebRTC 预留 | `video.html` |

## 文件

- `index.html`：语音/文字演练网页版，内置题库与离线演示模式；录音按钮预留 ASR。
- `video.html`：视频演练页，本地摄像头预览；WebRTC 与远端连线为预留接口，未接 RTC 时为占位。

## 两种运行模式

1. **离线演示**：`CONFIG.apiBase` 留空，页面按题库轮流抛题，复盘给固定示例文案；适合答辩本地打开。
2. **接后端**：把 `apiBase` 填成自己的代理地址，页面把 `history` POST 给后端，由后端调大模型 / ASR，返回 `{ reply }`。密钥只放后端，不写进前端页面。

## 预留能力

- **录音**：🎙 按钮申请麦克风权限；ASR 未接入时降级文字作答。
- **摄像头**：当前版本未采集视频；如需形象演练，另行接入摄像头组件，并在隐私政策告知用途。

## 上线前置条件

- 域名 HTTPS + ICP 备案；
- 隐私政策说明录音/个人信息用途与留存期限；
- 使用已备案大模型，AI 生成内容标注；
- 录音转文字接 ASR 服务（腾讯云/阿里云/讯飞），后端代理调用。

## 小程序侧入口

吉利专区复制本页面地址，提示用户在浏览器打开。地址在 `pages/geely/index.js` 的 `H5_INTERVIEW_URL` 中配置。
